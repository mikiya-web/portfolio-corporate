# BuildRise コーポレートサイト

架空の建築会社「BuildRise株式会社」を想定した、
複数ページ構成のコーポレートサイトです。

## 公開URL

https://mikiya-web.github.io/portfolio-corporate/

## 制作目的

会社案内・事業内容・施工事例・採用情報などを整理し、
企業の情報を複数ページで伝えるサイトの制作に取り組みました。

HTML・CSSによるレスポンシブ対応と、
JavaScriptによるメニュー・絞り込み・フォームの処理を実装しています。

## 使用技術

- HTML
- CSS
- JavaScript
- Google Fonts / Material Symbols
- Git / GitHub
- GitHub Pages

## ページ構成

- index.html：トップ
- about.html：会社案内
- service.html：事業内容
- works.html：施工事例一覧
- news.html：お知らせ一覧
- recruit.html：採用情報
- contact.html：お問い合わせ
- contact-thanks.html：入力確認完了のデモ
- demo.html：未実装ページの案内

## 主な実装

- 複数ページ間のナビゲーション
- レスポンシブなレイアウト
- スマホ用メニュー
- お知らせのカテゴリー絞り込み
- お問い合わせページのFAQ開閉
- フォームの必須入力・メール形式・電話番号の文字形式チェック
- エラー表示と最初のエラー欄へのフォーカス移動
- 入力チェック後のデモ完了ページへの遷移

## 工夫した点

### 共通JavaScriptの利用

各機能で必要な要素が存在するかを確認してから処理を実行し、
複数ページで同じJavaScriptファイルを使えるようにしています。

### 絞り込みの連続操作への対応

カテゴリーを連続で切り替えた場合は、
前のタイマーを取り消して、最後に選んだカテゴリーを反映します。

### フォームの入力確認

項目ごとにエラーメッセージを表示し、
エラーがある場合は最初の該当欄へフォーカスを移します。

フォームはデモであることを明記し、
実際の送信を行わずに完了ページへ移動します。

### スマホ表示の改善

画面幅に合わせてレイアウトを切り替えています。
採用バナーでは、矢印への過剰な幅指定を修正し、
文字とボタンが画像内に収まるように調整しました。

## デモとしての範囲

- 会社・住所・電話番号・施工実績・満足度などは架空の設定です。
- フォームの入力内容は送信・保存しません。
- お問い合わせの受付や返信は行いません。
- 施工事例詳細・お知らせ詳細・スタッフ紹介・
  プライバシーポリシー・サイトマップは実装対象外です。
- 未実装ページへのリンクは、デモ案内ページへ移動します。
- ページネーションは表示用のサンプルで、ページ切り替え機能はありません。
- SNSの実アカウントとの連携はありません。

## ファイル構成

- 各HTMLファイル：ページの構造・内容
- style.css：共通の装飾・ページ別レイアウト
- script.js：メニュー・絞り込み・FAQ・フォームの処理
- reset.css：リセット用CSSファイル
- image-*/：ページ別の画像

## ローカルでの確認方法

リポジトリをクローンし、index.htmlをブラウザで開いてください。

パッケージのインストールやビルドは不要です。
外部フォント・アイコン・地図の表示にはインターネット接続が必要です。
